# Follow-up Sequences

## Sequence model

Sequence
→ steps
→ trigger/delay
→ eligibility conditions
→ message
→ stop conditions

## Example

Step 1: initial
Delay: 3 days
Step 2: follow-up
Delay: 4 days
Step 3: value follow-up
Delay: 5 days
Step 4: final close

## Stop conditions

- reply
- positive outcome
- opt-out
- do_not_contact
- lead closed
- campaign paused

## Scheduling

Use jobs, not long-running server timers.
