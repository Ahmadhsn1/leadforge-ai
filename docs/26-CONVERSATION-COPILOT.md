# AI Sales Copilot

## Input

Incoming message + conversation history + lead intelligence.

## Tasks

- classify intent
- summarize
- detect objections
- detect sentiment
- recommend next action
- generate response draft

## Safety

Never send a generated reply without the channel's supported automation rules and required human approval level.

## Example intents

pricing
availability
interest
not_interested
question
objection
unsubscribe
unknown

## Human takeover

Certain categories should be flagged for immediate human handling.
