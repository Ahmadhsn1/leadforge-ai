# Personalization Engine

## Inputs

- lead facts
- evidence
- intelligence
- score
- target service
- channel
- tone
- CTA

## Outputs

- primary message
- short message
- alternative message
- follow-up 1
- follow-up 2
- final follow-up

## Channel behavior

WhatsApp:
conversational, concise, direct.

Instagram:
shorter, lighter, natural.

Email:
structured and context-rich.

## Quality gate

Generated message is not automatically “good” because an LLM returned it.

Validate:

- factual consistency
- business name
- unsupported claims
- length
- repetition
- CTA
- prohibited language
