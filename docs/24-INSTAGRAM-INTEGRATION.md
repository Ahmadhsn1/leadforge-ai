# Instagram Integration

## Purpose

Prepare and, when officially supported for the connected business account/use case, send and receive Instagram messages.

## Adapter

validate recipient/context
create draft
send
schedule where supported
parse webhook
normalize event

## Rule

Use supported Meta/Instagram APIs and integrations.

Do not build login automation, private-data scraping or anti-bot bypasses.

## Message style

Short, conversational and channel-native.
