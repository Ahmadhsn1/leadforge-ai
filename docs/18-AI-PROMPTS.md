# AI Prompt System

## Rule

Prompts are code and must be versioned.

## Tasks

- classify_business
- analyze_business
- score_lead
- generate_message
- validate_message
- classify_reply
- summarize_conversation

## Prompt structure

System instructions
→ task objective
→ business facts
→ evidence
→ constraints
→ output schema

## Message generation constraints

- use only supplied facts
- no fabricated observations
- no fake urgency
- no guaranteed revenue claims
- no pretending to be a customer
- channel-specific length
- one clear CTA
- natural language

## Versioning

Store prompt_version with every AI result.
