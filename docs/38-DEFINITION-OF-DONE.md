# Definition of Done

Feature is done only when:

1. data model exists
2. API contract exists
3. authorization exists
4. input/output validation exists
5. happy path works
6. failure path works
7. retries/idempotency are handled
8. tests exist
9. logs/metrics exist
10. UI loading/error/empty states exist
11. docs exist
12. tenant isolation is tested

## Lead quality gate

High-quality lead requires:

- sufficient identity verification
- source
- evidence
- known contactability
- explainable score
- grounded AI output
- validated message
- suppression check
