# User Flows

## Flow A — First-time onboarding

Sign up → create workspace → choose objective → dashboard.

## Flow B — Create campaign

New campaign → define target → define filters → select source → select channel → preview → launch.

## Flow C — Campaign processing

Campaign launched → discovery → normalize → dedupe → verify → enrich → AI analyze → score → personalize.

## Flow D — Lead review

Lead list → filter by score/status → open lead → inspect evidence → inspect AI analysis → inspect recommended angle → review message → approve/edit.

## Flow E — Outreach

Approved message → queue → supported integration → send/schedule → event tracking → follow-up eligibility.

## Flow F — Reply

Incoming reply → webhook/event → store → AI classify → suggest action → human review/send → CRM update.

## Flow G — Closed-loop learning

Outcome → event → analytics → message/score performance → future recommendation improvement.

## Failure flow

Job failure → retry with backoff → dead-letter if permanent → visible error → manual retry.
